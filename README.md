# CuriosAPI-RS

A Rust port of the [Curios](https://github.com/TheIllusiveC4/Curios) accessory-slot API for
Minecraft 26.3 on the [Horizon](https://github.com/horizon-rust/horizon) native mod API.

Status: early port. See `docs/research/` for the API/behavior analysis that drives the design and
the PR description for the current scope and limitations.
